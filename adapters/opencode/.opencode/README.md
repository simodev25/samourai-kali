## Security Workflow

`/recon → /hunt → /analyze-vuln → /cve-lookup + /score → /poc → /collect-evidence → /cve-report → /remediate`

- `/recon`: map the target surface and exposed assets.
- `/hunt`: identify suspicious patterns and potential weaknesses.
- `/analyze-vuln`: validate and characterize discovered vulnerabilities.
- `/cve-lookup + /score`: enrich with CVE intelligence and severity scoring.
- `/poc`: produce a safe, controlled proof of concept.
- `/collect-evidence`: gather reproducible technical evidence.
- `/cve-report`: generate a structured vulnerability report.
- `/remediate`: define and apply corrective actions.

## Installed Artifacts

Samourai core is installed under `.samourai/core/`. The OpenCode adapter is installed under `.opencode/`.

- `.opencode/agent/*.md` (core, complementary, and cybersecurity agents)
- `.opencode/command/*.md` (delivery, extension, and cybersecurity commands)
- `.opencode/skills/*/SKILL.md` (development and cybersecurity skills)
- `.opencode/skills/project/*/SKILL.md` (generated project skills)
- `.samourai/core/governance/conventions/*`
- `.samourai/core/governance/lifecycle/*`
- `.samourai/core/governance/policies/*`
- `.samourai/core/templates/*`
- `.samourai/core/decisions/*`

`AGENTS.md` is not provided as a static file. It is generated by `/bootstrap` in the target project.

## Conventions

- Naming uses `kebab-case`
- One command = one file
- One agent = one file
- One skill = one folder with `SKILL.md`
