# POC Validation Blueprint

## Role

This blueprint produces a clear POC validation plan tied to vulnerability findings and exploitation conditions.

## When To Use

- Before validating a reported vulnerability.
- To structure reproducible POC verification in an isolated lab.
- To document expected manual and automated validation evidence.

## Expected Files

- `test.blueprint.yaml`: POC validation contract.
- `test-plan.template.md`: POC validation template.

## Minimal Example

```text
Generate a POC validation plan for ticket GH-123 with lab-only reproduction and evidence capture.
```
