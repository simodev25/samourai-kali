# Investigation Blueprint

## Role

This blueprint frames a reproducible vulnerability investigation: finding, exploitation hypotheses, observations, vulnerability root cause, and remediation recommendation.

## When To Use

- To investigate a reported security finding.
- To document reproducible evidence for vulnerability validation.
- Before remediation when the vulnerability root cause is not yet proven.

## Expected Files

- `debug.blueprint.yaml`: investigation contract.
- `debug-report.template.md`: fillable investigation report.

## Minimal Example

```text
Produce an investigation report for the authentication bypass finding in the staging lab.
```
